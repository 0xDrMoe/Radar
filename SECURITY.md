# Security policy

## Reporting a vulnerability

Please report security problems privately, never in a public issue or pull request.

- Preferred: use **Report a vulnerability** on this repository's Security tab (GitHub private
  vulnerability reporting).
- Or email support@cedartechsolutions.ca with "Security" in the subject.

Include what you found, how to reproduce it, and what an attacker could do with it. We will
acknowledge your report within 3 business days and keep you updated until it is resolved.

## Scope

In scope: this code, and the live service at radar.cheap and affiliate.radar.cheap.

When testing against the live service, please:

- use only accounts you own, and never access, change or delete other people's data;
- don't degrade the service (no load testing, spam, or automated scraping of the catalog);
- don't use social engineering, phishing or physical attacks;
- give us reasonable time to fix a problem before disclosing it publicly.

We won't take legal action against good-faith research that follows these rules.

## Supported versions

Only the latest commit on `main` is supported. Fixes are not backported.
